# Ghoul Times

A decorative, gently animated Halloween display built for TVs and large tablets (16:9 landscape). Its style comes from the "let the ghoul times roll" flyer.

Plain static HTML/CSS/JS, so there's no build step. Open `index.html` or serve the folder:

```sh
python -m http.server
```

Deploys to GitHub Pages through `.github/workflows/pages.yml` on every push to `main`.

## Music

Click the record button (bottom left) to toggle ambient music. With a keyboard or TV remote, press **M**, **OK/Enter**, or **Play/Pause**. Browsers block audio until someone interacts with the page, so music always starts off.

Tracks are public-domain US sound recordings published before 1926, taken from the [Great 78 Project](https://archive.org/details/georgeblood) on the Internet Archive and re-encoded as mono 64 kbps MP3s:
