# Ghoul Times

A decorative, gently animated Halloween display built for TVs and large tablets (16:9 landscape). Its style comes from the "let the ghoul times roll" flyer.

Plain static HTML/CSS/JS, so there's no build step. Open `index.html` or serve the folder:

```sh
python -m http.server
```

Deploys to GitHub Pages through `.github/workflows/pages.yml` on every push to `main`.
